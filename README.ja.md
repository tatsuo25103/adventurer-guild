# 冒険者ギルド

**[繁體中文](README.md)** · [English](README.en.md) · [Deutsch](README.de.md) · 日本語

「冒険者ギルド」は、日々の生活習慣、学習目標、家庭やグループ内の役割を RPG 風のギルドクエストに変える Android アプリです。保護者、介護者、教師、サークル運営者などがクエストと報酬を管理し、子どもやメンバーはクエストを達成して GP と EXP を獲得します。

> **現在の状態：V0.2.0 Public Beta。** 機能、データ形式、サーバー API は今後変更される可能性があります。重要な情報は別途記録してください。

## インストール

- Android 7.0（API 24）以上が必要です。
- GitHub Releases から `adventurer-guild-0.2.0-debug.apk` をダウンロードします。
- ブラウザーまたはファイル管理アプリに「不明なアプリのインストール」を許可し、APK を開きます。
- ローカルデータを残したまま更新する場合は、新しい APK を既存アプリへ上書きインストールしてください。**先に旧版をアンインストールしないでください。**

更新には、同じパッケージ名、同じ署名、より大きい `versionCode` が必要です。現在の Public Beta はテスト署名であり、ストア向け正式版ではありません。

## クイックスタート

1. 端末 UUID アカウントを作成し、表示名を設定します。
2. 冒険者またはギルド管理側として入ります。
3. ギルドを作成するか、招待コード／QR コードで参加します。
4. 管理側がクエストと報酬を公開します。
5. 冒険者がクエストを達成して結果を報告します。
6. 権限を持つ管理者が審査し、GP／EXP を確定します。

1 つのアカウントで複数のギルドに参加でき、ギルドごとに異なる役割を持てます。ただし、同じギルドで冒険者と管理側を兼任することはできません。

## 主な機能

### 冒険者

- 公開掲示板より先に、自分が実行中のクエストを確認できます。
- 任意クエストを受注できます。日次、週次、月次の定期クエストは自動で割り当てられます。
- テキスト報告、超過達成の申請、クエストで指定された場合のみ Nearby の対面確認を利用できます。
- GP／EXP、レベル、ランク、称号を管理し、報酬を交換できます。
- ギルド別に複数のホーム画面ウィジェットを設定できます。

### ギルド管理側

- ギルド、招待コード、再利用 QR コード、ワンタイム QR コードを管理できます。
- クエストの作成、予約、編集、取り下げ、テンプレート保存ができます。
- 特定の冒険者や、1 人以上の専任審査者を指定できます。
- 通常審査と Nearby 対面審査を別の権限として管理できます。
- メンバー、役職、権限、ギルド休暇、報酬、交換申請を管理できます。

ギルド長はすべての権限を持ちます。クエストに専任審査者を指定した場合、通常の審査権限を持つ他の管理者も審査できません。ギルド長のみ例外です。

## クエスト種別

| 種別 | 特徴 |
| --- | --- |
| デイリークエスト | 選択した曜日に有効となり、その日の周期で精算 |
| ウィークリー依頼 | 選択した 1 曜日に更新 |
| マンスリークエスト | 指定日に更新。存在しない日付は月末として処理 |
| 常設依頼 | 掲示を続け、上限付きで何度も報告可能 |
| 戦団編成令 | 1 つの活動を人数制限付きの役割へ分け、報酬と罰則を個別設定 |
| 期間限定イベント | 明確な開始・終了条件を持つ限定クエスト |
| メインクエスト | 物語や機能を段階的に解放する進行チェーン |
| 昇格試練 | 条件を満たした冒険者が挑むランク昇格クエスト |

実績は独立したシステムであり、クエスト種別には含まれません。

## データとプライバシー

- 端末 UUID が主なアカウント識別子です。機種変更時には、有効時間が短く 1 回だけ使える移行コードを利用できます。
- Cloudflare Workers と D1 は、調整に必要な最小限のテキスト状態のみを同期します。
- 写真、動画、詳細な証明は利用者の端末に残ります。Nearby を有効にしたクエストでは、管理者が対面で証明を確認し、2 台の端末間で審査を確定します。
- GitHub Issues に実在する子どもの情報、招待コード、UUID、移行コード、非公開の証明を投稿しないでください。

## 開発とビルド

Kotlin、Jetpack Compose、MVVM、Gradle、および任意の Cloudflare Workers + D1 バックエンドを使用しています。

```powershell
Copy-Item private.properties.example private.properties
.\gradlew.bat :app:assembleDebug
```

`private.properties` には自分のバックエンド URL と公開検証鍵を設定してください。認証情報、秘密鍵、データベース ID、本番サービス URL はコミットしないでください。

## Public Beta の既知の制限

- 配布 APK はデバッグ署名の公開テスト版です。
- 旧端末を失う前に移行コードを発行していない場合、アカウント復旧には制限があります。
- 複数端末によるオフライン同時編集の競合処理には、さらに実機テストが必要です。
- Nearby の代表的なテストには 2 台の実 Android 端末が必要です。

本アプリの目的は協力とコミュニケーションを促すことです。子どもやメンバーを辱める、脅す、過度に監視する、または金銭的に搾取する目的で使用しないでください。
