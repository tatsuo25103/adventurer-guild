## 本版重點

### 帳號與公會

- 使用裝置 UUID 建立帳號，可自訂顯示名稱。
- 提供一次性移機碼，讓帳號可從舊手機移至新手機。
- 同一帳號可加入或管理多個公會，但不能在同一公會同時擔任冒險者與管理方。
- 支援一般邀請碼、QR Code、可替換邀請及一次性邀請。

### 任務

- 支援每日、每週、每月、常駐、戰團編成令、限時討伐令、命運篇章及晉階試煉。
- 固定週期任務不需接取，依指定週期自動生效及結算。
- 支援公告、開放接取、有效期間、指定冒險者、指定審核人員、自動審核、處罰與超額提交。
- 管理方可查看任務執行者與個別冒險者的任務狀態。

### 面對面互動

- Nearby 為任務建立時可選的特殊提交方式，不會套用到所有任務。
- 照片、影片等證明由管理方當面查看，不上傳至專案伺服器。
- Nearby 一般審核、指定審核人員及公會會長權限分開處理。

### 成長、權限與獎勵

- GP、EXP、Level、Title 與木、鐵、銅、銀、金、密銀、精鋼名牌。
- 分層管理公會成員、職務與權限。
- 獎勵商店、GP 兌換及管理方審核。
- 公會休假可暫停常態循環任務及其未完成處罰。

### 介面與小工具

- 冒險者任務頁優先顯示手上任務，再顯示任務看板。
- 公會內提供公會首頁、公會入口、重新整理與 App 入口快捷鍵。
- Android 桌面小工具可依公會設定，並可放置多個不同公會的小工具。
- 支援繁體中文、English、Deutsch 與日本語。

### 雲端與安全

- Cloudflare Workers + D1 僅同步必要文字狀態，不保存任務證明媒體。
- 請求包含裝置簽章、時間戳與 nonce，伺服器端再次檢查公會身分及操作權限。
- 敏感設定、Firebase 設定檔、Worker 位址、資料庫 ID、簽章金鑰及本機資料不納入公開版本庫。

## 已知限制

- 目前 APK 是公開測試用 Debug 簽章，不是商店正式簽章。
- 裝置遺失且沒有移機碼時，帳號復原能力有限。
- 離線與多人同時修改後的衝突提示仍需擴大測試。
- Nearby 需兩台支援的 Android 裝置在現場測試；模擬器無法完整代表實機行為。
- 公開測試期間請勿把本 App 當成唯一的家庭紀錄、財務系統或安全監控工具。
