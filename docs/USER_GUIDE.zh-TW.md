# 冒險者公會 V0.2.0 使用手冊

[返回專案首頁](../README.md) · [下載 V0.2.0 公開測試版](https://github.com/tatsuo25103/adventurer-guild/releases/tag/v0.2.0) · [V0.2.0 更新說明](RELEASE_NOTES_V0.2.0.zh-TW.md)

本手冊適用於 V0.2.0 Public Beta。畫面與資料格式仍可能在後續公開測試版調整。

## 1. 第一次啟動

1. 選擇「使用此裝置的 UUID 帳號」。App 會為裝置建立永久帳號識別。
2. 設定自己的顯示名稱。此名稱可以稍後修改，不需要把真實姓名當成帳號。
3. 選擇本次入口：
   - **冒險者**：加入公會、查看任務、提交成果及兌換獎勵。
   - **公會管理方**：建立或管理公會、發布任務、審核及管理成員。

同一帳號可以在不同公會使用不同身分，也可以加入多個公會；但同一帳號不能在同一個公會同時擔任冒險者與管理方。

## 2. 頁面導覽

公會內頁頂端提供以下快捷入口：

| 按鈕 | 功能 |
| --- | --- |
| 首頁 | 返回目前公會的首頁 |
| 公會入口 | 返回已加入或管理的公會清單 |
| 重新整理 | 在登入或資料異動後同步最新文字狀態 |
| App 入口 | 返回選擇冒險者／公會管理方的入口 |

Android 系統返回鍵與畫面上的「返回」按鈕用於回到上一層，不會直接切換公會身分。

## 3. 建立公會

1. 從 App 入口選擇「以公會管理方身分進入」。
2. 在公會入口開啟「建立公會」。
3. 輸入公會名稱並建立。
4. 建立者會成為公會會長。會長擁有所有公會權限，也可以建立職務並將權限委派給其他管理員。

## 4. 邀請成員

公會首頁可查看及管理邀請資料：

- **一般邀請碼／QR Code**：可供多位成員加入；需要時可以替換，舊邀請隨即失效。
- **一次性 QR Code**：僅供一人使用，使用後失效，適合現場加入。
- **管理方邀請**：加入管理名單後預設不代表擁有全部權限，需由會長指派職務或權限。

請勿把邀請碼公開貼在不受控的社群。若懷疑邀請碼外洩，請立即替換。

## 5. 加入與切換公會

1. 從 App 入口選擇「以冒險者身分進入」。
2. 在公會入口選擇加入公會，輸入邀請碼或掃描 QR Code。
3. 若公會啟用加入審核，需等待具有人員審核權限的管理方核准。
4. 核准後，該公會會出現在自己的冒險者公會清單。

使用者只能進入自己已加入或管理的公會。切換公會時，任務、小工具、GP、EXP、職務與權限都應依該公會分開顯示。

## 6. 建立任務

管理方在任務頁建立任務時，可依任務類型設定：

- 任務名稱、說明、GP、EXP、未完成處罰。
- 公告時間、開放接取時間及有效期間。
- 是否為固定週期、星期或每月刷新日。
- 是否指定一位或多位冒險者。
- 是否允許超額提交。
- 是否自動審核。自動審核不會自動計算超額獎勵。
- 是否需要 Nearby 當面簽核。
- 是否指定一位或多位審核人員。

指定審核人員後，其他管理員即使具有一般審核權限，也不能審核該任務；公會會長例外。

### 任務狀態

| 狀態 | 說明 |
| --- | --- |
| `draft` | 草稿，尚未發布 |
| `published` | 已發布，等待公告或開放時間 |
| `available` | 可接取或目前週期已生效 |
| `accepted` | 已由冒險者接取 |
| `in_progress` | 執行中 |
| `submitted` | 已提交，等待審核 |
| `approved` | 已核准並結算獎勵 |
| `rejected` | 已退回或拒絕 |
| `expired` | 已到期 |
| `cancelled` | 已取消或下架 |

固定的每日、每週、每月任務為強制週期任務，不需要冒險者另行接取。週期結束後直接進入下一週期，不提供補交或寬限。

## 7. 冒險者完成任務

1. 在任務頁先查看「手上任務」，再查看「任務看板」。
2. 一般任務先接取；固定週期任務會自動出現在手上任務。
3. 開啟任務詳情，確認說明、期限、獎勵、處罰與提交方式。
4. 輸入文字回報；若公會允許空白回報，也可直接送審。
5. 若表現超過任務標準，可勾選超額提交並說明成果，由管理方決定額外獎勵。

只有建立任務時勾選 Nearby 的任務，才會在最後顯示 Nearby 當面簽核流程。一般任務不需要 Nearby。

## 8. 審核與結算

管理方審核時應確認：

- 自己是否具有一般審核或 Nearby 審核權限。
- 任務是否指定特定審核人員。
- 提交是否屬於目前週期，避免重複結算。
- GP、EXP、額外獎勵或處罰是否正確。

核准後才發放 GP／EXP。自動審核任務會在一般完成回報後自動通過，但管理方仍可事後依紀錄修正獎勵或處罰。

## 9. Nearby 當面簽核

Nearby 是特殊的面對面流程，不是照片或影片的雲端上傳服務：

1. 冒險者在自己的手機開啟指定任務與成果。
2. 管理方當面查看手機上的照片、影片或其他證明。
3. 雙方開啟 Nearby 簽核畫面，讓裝置在近距離完成確認。
4. 伺服器只保存必要的文字送審與簽核狀態，不保存證明媒體。

若任務沒有指定審核人員，只有具備 Nearby 審核權限的管理員能完成簽核。若任務指定了審核人員，則只有被指定的管理員與公會會長可以處理。

## 10. 公會休假

具備公會休假設定權限的管理方可以設定休假期間。休假時，常態循環任務暫停，避免冒險者因家庭旅行、學校假期或公會活動中止而受到未完成處罰。

限時活動或個別任務是否繼續有效，應由任務設定及管理方公告決定。

## 11. GP 與獎勵商店

- 管理方建立獎勵並設定所需 GP、數量與說明。
- 冒險者提出兌換後，GP 不應在未確認前被重複扣除。
- 具備兌換審核權限的管理方確認實際交付後完成兌換。
- 實體、金錢或具有年齡限制的獎勵應由成年人依所在地規範管理。

## 12. 桌面任務小工具

新增小工具時可以選擇要顯示的公會。使用者可放置多個小工具，分別顯示不同公會：

- 未完成、待審及任務類型統計。
- 目前公會的手上任務清單。
- 快到期與即將到期的顏色提示。
- 點擊任務直接開啟該公會、該冒險者身分下的任務詳情。

若小工具資料與 App 不一致，先開啟對應公會並重新整理，再回到桌面等待小工具更新。

## 13. 更換手機

目前帳號以裝置 UUID 為主要識別。更換手機前：

1. 在舊手機的公會入口產生一次性移機碼。
2. 在有效時間內於新手機選擇「從舊手機繼承帳號」。
3. 輸入移機碼並確認顯示名稱與公會清單。
4. 確認成功前，不要解除安裝舊手機上的 App。

移機碼只能使用一次，並會在短時間後失效。若舊手機已遺失且沒有可用移機碼，目前公開測試版的復原能力有限。

## 14. 語言切換

App 支援繁體中文、English、Deutsch 與日本語。語言選項位於 App 入口或設定區。切換後，使用者自行輸入的公會、任務與獎勵文字不會自動翻譯。

## 15. 常見問題

### Android 顯示「未安裝應用程式」

先確認下載檔案完整，並允許目前的瀏覽器或檔案管理器安裝未知應用程式。若手機已安裝舊版，更新 APK 必須使用相同套件名稱與簽章，且 `versionCode` 必須更高。

**請勿為了更新而先解除安裝**，否則本機資料可能消失。

### 為什麼任務沒有出現在冒險者頁面？

檢查公告時間、開放時間、有效星期、指定對象、公會身分及任務是否已發布。管理方的任務管理清單和冒險者的可執行任務清單本來就有不同篩選條件。

### 為什麼不能審核？

檢查任務是否要求 Nearby、是否指定其他審核人員，以及目前管理職務是否具備相應權限。公會會長可以處理所有任務。

### 為什麼 Nearby 沒有出現？

Nearby 只會出現在建立任務時已勾選 Nearby 的任務。一般文字提交不會顯示此步驟。

## 16. 回報問題

請在 [GitHub Issues](https://github.com/tatsuo25103/adventurer-guild/issues) 提供：

- App 版本與 Android 版本。
- 操作身分與公會角色。
- 可重現步驟、預期結果與實際結果。
- 已遮蔽姓名、邀請碼、UUID、移機碼及私人內容的截圖。

請不要公開貼出真實兒童資料、證明照片、伺服器密鑰或完整裝置識別碼。
